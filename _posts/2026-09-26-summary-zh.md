## [Ollama v0.40.0-rc0 在 Apple Silicon 上默认启用 MLX 运行时](https://github.com/ollama/ollama/releases/tag/v0.40.0-rc0) ⭐️ 7.0/10

Ollama 发布了候选版本 v0.40.0-rc0，在该版本中，Apple Silicon 设备上受 MLX 运行时支持的模型架构将自动使用 MLX 运行。这意味着 Mac 用户拉取并运行 qwen3.8 等模型时将默认走 MLX 路径，官方还将在预发布期间测试并启用更多模型。 将 MLX 设为默认运行时，对这款被广泛使用的本地 LLM 运行时而言是一次重要的平台优化，有望为 Mac 用户带来更好的性能与效率。这也表明 Ollama 与苹果自家机器学习技术栈的进一步靠拢，可能影响未来 Apple 硬件上本地推理的实现方式。 这是一个候选版本而非稳定版，因此最终发布前行为仍可能变化。目前只有 MLX 运行时已支持的模型架构才会自动走 MLX，完整变更日志对比的是 v0.34.4 与 v0.40.0-rc0。

github · github-actions[bot] · 9月25日 03:31

**背景**: Ollama 是一个开源运行时，让用户通过 'ollama pull'、'ollama run' 等命令在自己的硬件上本地下载并运行大语言模型。MLX 是苹果机器学习研究团队为 Apple Silicon 开发的机器学习数组框架，旨在让模型在 Mac 上高效灵活地执行。此前 Ollama 在 Mac 上主要依赖 llama.cpp 等其他后端，因此将受支持模型默认切换到 MLX 是一次值得关注的架构转变。

## [Aikido Security 发布 Altar-1：从 GLM-5.3 剪枝至 328 GB 的开源权重安全模型](https://news.google.com/rss/articles/CBMi0wFBVV95cUxPdktrSkNxWFBjNWhaTENsSllWMGpVbjVFY1dNZGtSaTV0elF3Ti1MeUxMeklJcEtWMUJwUjltRE9yNmxVRG5tbG9iSnNqcjBJT181QzFTTGNSZVV1ZTgwYXlITGF2eTBMX0hGd2ZxNTRVbjc3aW9yU0lzRUQ3MUhkb1dWazZnRWJwcTNYRTdEMkRVODEybFQ5VE5wcWhqQVZGMXpUZ3hOWmU5N1BHZVpGMEExWGE2TGp2QnRKTzdPbE9TRTJLaWFSVDJGN3BRZkNORVpz0gHTAUFVX3lxTE92S2tKQ3FYUGM1aFpMQ2xKWVYwalVuNUVjV01ka1JpNXR6UXdOLUx5TEx6SUlwS1YxQnBSOW1ET3I2bFVEbm1sb2JKc2pyMElPXzVDMVNMY1JlVXVlODBheUhMYXZ5MExfSEZ3ZnE1NFVuNzdpb3JTSXNFRDcxSGRvV1ZrNmdFYnBxM1hFN0QyRFU4MTJsVDlUTnBxaGpBVkYxelRneE5aZTk3UEdlWkYwQTFYYTZManZCdEpPN09sT1NFMktpYVJUMkY3cFFmQ05FWnM?oc=5) ⭐️ 7.0/10

Aikido Security 发布了其首个开源权重安全模型 Altar-1，它是 Z.AI 的 GLM-5.3 的压缩版本，从原始的 1.51 TB 剪枝至 328 GB。该模型被设计为可在客户自控的基础设施内运行，目标是在安全场景中实现前沿级推理能力的生产级部署。 大多数能力强的开源权重模型在保持前沿级推理质量的同时，仍难以在生产规模上部署，因此一个面向安全领域、体积大幅缩小的模型降低了那些需要将敏感安全数据保留在自有基础设施中的组织的门槛。这也反映出垂直领域、经过领域调优的开源权重模型正在受监管和隐私敏感行业挑战闭源前沿 API 的更大趋势。 基础模型 GLM-5.3 是一个稀疏混合专家（MoE）Transformer，总参数量 753B，每个 token 约激活 40B 参数，包含 78 个解码层、每个 MoE 层 256 个路由专家（top-8 路由加 1 个共享专家），并采用 DeepSeek 稀疏注意力。剪枝通过移除不重要的参数来缩小模型体积并加速推理，通常随后需要微调以恢复精度，不过 Aikido 所采用的具体剪枝与微调方案在公告中并未详细说明。

google_news · MarkTechPost · 9月25日 15:14

**背景**: GLM-5.3 是 Z.AI 最新的旗舰模型，与 GLM-5.2 使用相同的基础模型，所有提升均来自后训练，在复杂软件工程和智能体任务上表现尤为突出。模型剪枝是一种标准的压缩技术，通过移除神经网络中不重要的权重来缩小体积并实现更高效的推理。开源权重模型是指训练好的参数可公开下载的模型，使组织能够自行托管，而不必依赖厂商的 API。
