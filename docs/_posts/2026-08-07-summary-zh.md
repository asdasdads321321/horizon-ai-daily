## [双向扩散模型可预测自身滚动误差](https://www.reddit.com/r/MachineLearning/comments/1vh2gn1/roundtrip_consistency_bidirectional_diffusion/) ⭐️ 8.0/10

该论文提出训练一个单一的条件潜在扩散模型，通过方向标志使动力系统在时间上前进或后退，利用往返差异作为无真实标签的滚动误差的自监督代理。这种双向方法在正反两个方向上都优于两个专门模型。 这项工作解决了自回归生成模型的一个关键限制——长时间滚动中的误差累积——通过提供一种无需测量的测试时误差信号。它对视频生成、数字孪生和其他动力系统预测具有广泛的适用性，可能提高生成模型的可靠性和可信度。 该方法仅需一次额外的滚动（先前进再后退），无需集成、保留数据或控制方程。在 LE-PDE-UQ 湍流纳维-斯托克斯基准上，单个双向模型以十分之一的训练成本达到十模型集成精度的 1.3 倍以内，并具有最佳的免训练像素级校准。

reddit · r/MachineLearning · /u/Clean-Hovercraft5825 · 8月6日 12:10

**背景**: 自回归模型，如潜在扩散或流模型，通过基于先前输出进行条件生成序列，这导致长时间滚动中的误差累积。潜在扩散模型在压缩的潜在空间中执行扩散，从而实现高效生成。往返一致性是一种自监督方法，其中前向模型的输出由后向模型映射回来，差异作为误差信号。

## [Datasette 1.0a38 修复混合公开/私有设置中的 SQL 注入漏洞](https://simonwillison.net/2026/Aug/6/datasette/#atom-everything) ⭐️ 7.0/10

Datasette 1.0a38 修复了一个 SQL 注入漏洞，该漏洞影响在同一数据库中同时提供公开和私有表、并通过 Datasette 权限系统配置访问的实例。该修复也已移植到 Datasette 0.65.3。 此安全修复对于同时公开公开表和私有表的 Datasette 用户至关重要，因为它可防止通过 SQL 注入未经授权地只读访问私有数据。它强调了数据发布工具中持续需要强大安全性的重要性。 该漏洞允许有权访问任何公开表的用户，即使禁用了 execute-sql 权限，也能执行 SQL 注入攻击，从而获得对私有表的只读访问权限。建议管理员在受影响的数据库上禁用 execute-sql 权限以缓解此问题。

rss · Simon Willison · 8月6日 18:24

**背景**: Datasette 是一个用于发布和探索数据的工具，常用于在线共享数据集。它包含一个权限系统，可以限制对特定表的访问，但此漏洞通过原始 SQL 查询绕过了这些限制。该修复针对的是同一数据库中共存公开表和私有表的特定边缘情况。

## [无需重新训练即可加速大语言模型的框架](https://news.google.com/rss/articles/CBMiXEFVX3lxTE9CeG5TTFFJY2VpZDhXX3JtQmFmaDExX2xCdkxYZ1NFelloamROWW1OQnU3SU5KUmJ3Q0NRN2xzZVhHUXZfSHFCdVZHY1RUYXAwVzFCYlZUX1EzMEN4?oc=5) ⭐️ 7.0/10

日本北陆先端科学技术大学院大学（JAIST）的 Nguyen-Khang Le 团队开发了 UniSpec，这是一个即插即用、无需训练的推测解码框架，可在不改变模型输出或无需额外训练的情况下加速大语言模型推理。该框架自动为每个硬件平台校准最佳草稿大小，并通过置信度引导扩展构建有效的草稿树。 这一进展解决了对高效大语言模型推理的迫切需求，在不影响输出质量的情况下降低延迟和计算成本。它可能促进大语言模型在多样化硬件（包括资源受限环境）上的更广泛部署，并提高多语言应用的可及性。 UniSpec 为检索到的 n-gram 估计置信度分数，并使用置信度引导扩展来构建更有效的草稿树。团队还引入了 Multi-SpecBench，这是一个涵盖七种语言和七种生成任务的多语言基准，用于评估英语以外的推测解码。

google_news · EurekAlert! · 8月6日 05:52

**背景**: 大语言模型（LLM）是在大量文本数据上训练的人工智能系统，用于生成类似人类的文本。推理（生成输出的过程）可能计算成本高昂，尤其是对于自回归模型，因为它们需要逐个生成 token。推测解码是一种技术，使用较小的草稿模型提出多个 token，然后由较大的模型并行验证，从而在不改变输出的情况下加速推理。
